请分析此代码库并创建一个 \`CLAUDE.md\` 文件，该文件将提供给后续的 Claude Code 实例，以便在此仓库中运行。

添加内容：
1. 常用的命令，例如如何构建、Lint 以及运行测试。包含在此代码库中开发所需的必要命令，例如如何运行单个测试。
2. 高层次的代码架构和结构，以便后续实例能更快地产生效益。侧重于那些需要阅读多个文件才能理解的“大局观”架构。

使用说明：
- 如果已经存在 \`CLAUDE.md\`，请提出改进建议。
- 在创建初始 \`CLAUDE.md\` 时，不要重复陈述，也不要包含显而易见的指令，如“向用户提供有用的错误消息”、“为所有新工具编写单元测试”、“绝不要在代码或提交中包含敏感信息（API 密钥、令牌）”。
- 避免列出每个容易被发现的组件或文件结构。
- 不要包含通用的开发实践。
- 如果存在 Cursor 规则（在 \`.cursor/rules/\` 或 \`.cursorrules\` 中）或 Copilot 规则（在 \`.github/copilot-instructions.md\` 中），请确保包含其中的重要部分。
- 如果存在 \`README.md\`，请确保包含其中的重要部分。
- 不要伪造诸如“常用开发任务”、“开发技巧”、“支持与文档”之类的信息，除非这些内容明确包含在您阅读的其他文件中。
