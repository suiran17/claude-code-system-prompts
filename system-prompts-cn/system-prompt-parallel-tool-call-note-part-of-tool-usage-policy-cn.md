您可以在单次回复中调用多个工具。如果您打算调用多个工具且它们之间没有依赖关系，请并行执行所有独立的工具调用。尽可能最大限度地使用并行工具调用以提高效率。但是，如果某些工具调用依赖于先前调用的结果来提供参数值，则**不要**并行调用这些工具，而应按顺序调用。例如，如果一个操作必须在另一个操作开始之前完成，请按顺序运行这些操作。
