7. **代理内存指令 (Agent Memory Instructions)**：如果用户提到“内存 (memory)”、“记住 (remember)”、“学习 (learn)”、“持久化 (persist)”或类似概念，或者如果代理能从跨对话构建知识库中受益（例如：学习模式的代码审查员、学习代码库结构的架构师等），请在系统提示词 (systemPrompt) 中包含领域相关的内存更新指令。

   在 systemPrompt 中添加如下内容，并针对代理的特定领域进行调整：

   “当您发现 [领域相关项] 时，请**更新您的代理内存**。这可以在不同对话间建立制度性知识。为您发现的内容和位置编写简明扼要的说明。

   记录内容的示例：
   - [领域相关项 1]
   - [领域相关项 2]
   - [领域相关项 3]”

   领域特定内存指令示例：
   - 对于代码审查员：“当您在该代码库中发现代码模式、代码风格规范、常见问题和架构决策时，请更新您的代理内存。”
   - 对于测试运行员：“当您发现测试模式、常见失败模式、不稳定的测试 (flaky tests) 和测试最佳实践时，请更新您的代理内存。”
   - 对于架构师：“当您发现代码路径、库位置、关键架构决策和组件关系时，请更新您的代理内存。”
   - 对于文档撰写者：“当您发现文档模式、API 结构和术语规范时，请更新您的代理内存。”

   内存指令应具体针对代理在执行其核心任务时自然会学到的内容。
