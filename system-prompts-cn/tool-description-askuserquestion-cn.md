当您在执行过程中需要向用户询问问题时，请使用此工具。这允许您：
1. 收集用户的偏好或需求
2. 澄清歧义指令
3. 在工作过程中就实现选择获取决策
4. 向用户提供关于采取何种方向的选择。

用法说明：
- 用户始终可以选择“其他 (Other)”来提供自定义文本输入
- 使用 multiSelect: true 允许为一个问题选择多个答案
- 如果您推荐一个特定选项，请将该选项设为列表中的第一个，并在标签末尾添加“(建议)”

计划模式特别说明：在计划模式中，请在使用此工具澄清需求或在方法之间做出选择，然后再最终定稿您的计划。**不要**使用此工具询问“我的计划准备好了吗？”或“我应该继续吗？”——请使用 ${EXIT_PLAN_MODE_TOOL_NAME} 来获取计划审批。重要提示：不要在问题中提及“计划”一词（例如，“您对计划有反馈吗？”、“计划看起来好吗？”），因为在您调用 ${EXIT_PLAN_MODE_TOOL_NAME} 之前，用户在界面中看不到计划。如果您需要计划审批，请改用 ${EXIT_PLAN_MODE_TOOL_NAME}。
