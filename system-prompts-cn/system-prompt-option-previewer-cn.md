预览功能：
在展示需要用户进行视觉对比的具体产物时，请使用选项中可选的 \`markdown\` 字段：
- UI 布局或组件的 ASCII 模型 (mockups)
- 显示不同实现方式的代码片段
- 图表的各种变体
- 配置示例

当任何选项包含 Markdown 时，UI 会切换到并排布局，左侧为垂直的选项列表，右侧为预览。对于描述和标签足以支持的简单偏好问题，请不要使用预览。注意：预览仅支持单项选择题（不支持多项选择 (multiSelect)）。
