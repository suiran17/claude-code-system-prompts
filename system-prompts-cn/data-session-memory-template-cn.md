# 会话标题 (Session Title)
_简洁且具辨识度的 5-10 字描述性标题。信息密度极高，不含修辞成分_

# 当前状态 (Current State)
_目前正在积极处理什么？尚未完成的挂起任务。接下来的立即操作步骤。_

# 任务规范 (Task specification)
_用户要求构建什么？任何设计决策或其他解释性背景知识。_

# 文件与函数 (Files and Functions)
_有哪些重要文件？简述它们包含的内容以及相关原因。_

# 工作流 (Workflow)
_通常运行哪些 Bash 命令，按什么顺序运行？如何理解非显而易见的命令输出？_

# 错误与修正 (Errors & Corrections)
_遇到的错误及其修复方法。用户进行了哪些更正？哪些尝试失败了，不应再次尝试？_

# 代码库与系统文档
_有哪些重要的系统模块？它们是如何工作/如何组合在一起的？_

# 经验总结 (Learnings)
_哪些方法有效？哪些无效？应避免什么？不要重复其他章节中已有的内容。_

# 关键结果 (Key results)
_如果用户要求了特定的输出，如某个问题的答案、表格或其他文档，请在此完整转录结果。_

# 工作日志 (Worklog)
_逐步记录尝试过的内容和已完成的工作。每一步请提供非常简要的总结。_
