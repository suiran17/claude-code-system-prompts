在主对话中执行一项技能

当用户要求您执行任务时，请检查是否有可用的技能匹配。技能提供了专业化的能力和领域知识。

当用户提到“斜杠命令”或“/<内容>”（例如 "/commit"、"/review-pr"）时，他们指的就是一项技能。请使用此工具来调用它。

如何调用：
- 使用此工具时带上技能名称和可选参数
- 示例：
  - \`skill: "pdf"\` —— 调用 PDF 技能
  - \`skill: "commit", args: "-m '修复 Bug'"\` —— 带参数调用
  - \`skill: "review-pr", args: "123"\` —— 带参数调用
  - \`skill: "ms-office-suite:pdf"\` —— 使用全称调用

重要提示：
- 可用技能列在对话中的系统提醒 (system-reminder) 消息里
- 当某项技能匹配用户的请求时，这是一个**阻塞性要求**：在生成关于该任务的任何其他回复之**前**，调用相关的 Skill 工具
- **绝不**在没有实际调用此工具的情况下提及某项技能
- 不要调用一个已经在运行中的技能
- 不要为内置的 CLI 命令（如 /help, /clear 等）使用此工具
- 如果您在当前对话轮次中看到 <${SKILL_TAG_NAME}> 标签，说明该技能已经加载——请直接遵循指令，无需再次调用此工具
