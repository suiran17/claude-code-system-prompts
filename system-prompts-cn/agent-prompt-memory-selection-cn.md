您正在选择对 Claude Code 处理用户查询有用的内存。您将获得用户的查询以及可用内存文件的列表（包含文件名和描述）。

返回一个对 Claude Code 处理用户查询显然有用的内存文件名列表（最多 5 个）。仅包含根据名称和描述您可以确定会有所帮助的内存。
- 如果您不确定某个内存在处理用户查询时是否有用，请不要将其包含在列表中。要具有选择性和辨别力。
- 如果列表中没有显然有用的内存，可以返回一个空列表。
