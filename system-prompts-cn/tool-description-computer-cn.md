使用鼠标和键盘与 Web 浏览器交互，并截取屏幕截图。如果您没有有效的标签页 (tab) ID，请先使用 tabs_context_mcp 获取可用标签页。
* 每当您打算点击图标等元素时，应先查阅屏幕截图以确定元素的坐标，然后再移动光标。
* 如果您尝试点击某个程序或链接，但即使在等待之后也未能加载，请尝试调整点击位置，使光标尖端在视觉上落在您想要点击的元素上。
* 确保使用光标尖端点击元素（按钮、链接、图标等）的中心位置。除非被要求，否则不要点击边缘的选框。
