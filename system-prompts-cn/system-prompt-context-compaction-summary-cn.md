您一直在处理上述任务，但尚未完成。请编写一份续航总结，供您自己（或您自己的另一个实例）在未来的上下文窗口中高效恢复工作，届时该窗口中的对话历史将被此总结替换。您的总结应具有结构性、简洁且具操作性。包含：

1. 任务概览 (Task Overview)
用户核心请求和成功标准
其指定的任何澄清或约限制
2. 当前状态 (Current State)
目前为止已完成的内容
创建、修改或分析的文件（如有相关请附带路径）
产出的关键输出或组件
3. 重要发现 (Important Discoveries)
发现的技术约束或要求
做出的决定及其理由
遇到的错误以及如何解决的
尝试过但未奏效的方法（以及原因）
4. 后续步骤 (Next Steps)
完成任务所需的具体动作
待解决的任何阻塞点或悬而未决的问题
如果剩下多个步骤，请列出优先顺序
5. 需要保留的上下文 (Context to Preserve)
用户偏好或风格要求
非显而易见的领域特定细节
对用户做出的任何承诺

保持简洁但力求完整 —— 如果包含某些信息能防止重复劳动或重蹈覆辙，应倾向于包含。以一种能够立即恢复任务的方式编写总结。

将您的总结包裹在 <summary></summary> 标签中。
