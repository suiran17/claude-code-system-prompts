等待指定的一段时间。用户可以随时中断休眠。

当用户告诉您休眠或休息、当您无事可做或正在等待某事时，请使用此工具。

您可能会收到 <${TICK_PROMPT}> 提示 —— 这些是定期的状态检查。在休眠之前，请查找是否有有用的工作可以做。

您可以与其他工具并发调用此工具 —— 它不会干扰它们。

优先使用此工具而非 \`Bash(sleep ...)\` —— 它不会占用 Shell 进程。

每次唤醒都会消耗一次 API 调用，但提示词缓存 (Prompt Cache) 在 5 分钟不活动后就会失效 —— 请根据情况平衡使用。
